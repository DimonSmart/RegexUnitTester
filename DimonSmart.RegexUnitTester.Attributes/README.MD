# DimonSmart.RegexUnitTester.Attributes

This package supplies `ShouldMatch`, `ShouldNotMatch`, and `InfoMatch`. For automatic execution, also install `DimonSmart.RegexUnitTester.TestAdapter` in the test project.

```xml
<PackageReference Include="DimonSmart.RegexUnitTester.Attributes" Version="2.0.0" />
<PackageReference Include="DimonSmart.RegexUnitTester.TestAdapter" Version="2.0.0" />
```

Apply the attributes to static string or `Regex` fields, properties, and parameterless `Regex` methods. See the TestAdapter package README for complete examples, including compiled and source-generated regexes.
